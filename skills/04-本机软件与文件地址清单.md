## 总结（程序员视角）

1. **启动 GPT**：`explorer.exe shell:AppsFolder\OpenAI.Codex_2p2nqsd0c76g0!App`；**关闭**：`taskkill /IM ChatGPT.exe /T /F`（连带 Codex.exe、codex.exe）。
2. **美国静态 IP 的可用通道**（本项目最关键的发现）：`127.0.0.1:<roxynet端口>` + `dirId:dirId` 认证 —— 实测返回 `<美国静态IP>`。roxynet 端口要动态查（枚举 roxynet 进程的监听端口），dirId 来自窗口数据目录名/`lumi.conf`。
3. **控制 Clash** 只有一条路：运行时枚举命名管道 `verge-mihomo-*`，在其上发 Clash REST API 请求（免 secret）。
4. **Clash 的持久化改造**走 `profiles\` 下三个扩展文件（节点/规则/代理组），改完需要应用"重新生成配置"（重启 Clash Verge 应用最省事）。
5. 所有路径/端口都在本文件里，程序中不要硬编码动态值（roxynet 端口、管道名、RoxyChrome 调试口）。
