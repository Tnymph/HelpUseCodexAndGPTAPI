## 分类知识摘要

### A. 网络/代理类
- **Chromium/Electron（含 ChatGPT 桌面版前端）**：Windows 上默认跟随系统代理（注册表改动即时生效）；env 变量无效；Store 版无法传 `--proxy-server`。【01/02】
- **codex 后端（Rust）**：默认不用系统代理，可用 `config.toml [features] respect_system_proxy` 或 env 变量或 TUN 解决。【02】
- **TUN**：网络层全接管，是"不泄漏"的唯一保险；本机已开。【03】
- **Roxy 静态 IP 通道**：roxynet 本地代理（HTTP+SOCKS5），凭据 = dirId:dirId；端口动态；依赖窗口打开 + Clash 活着。【01】

### B. 软件操作类
- **ChatGPT 应用**：启动 `explorer.exe "shell:AppsFolder\OpenAI.Codex_2p2nqsd0c76g0!App"`；关闭 `taskkill /IM ChatGPT.exe /T /F`；数据在 `%USERPROFILE%\.codex`。【02】
- **Clash Verge**：启动 = 运行 `E:\Clash Verge\clash-verge.exe`（自动恢复 TUN+系统代理）；关闭 = 杀应用 + 杀 SYSTEM 内核（管理员）+ 清系统代理；**没有官方 CLI**，控制靠命名管道 API。【03】
- **Roxy Browser**：窗口打开 = 正常启动后开窗（或用未文档化 CLI `--roxy-action launch-browser`）；关闭 = 先关窗口再退主程序（点 X 只最小化到托盘）。【01】

### C. 配置与文件类
- Clash 改造点：`profiles\pYSK1srNIfYO.yaml`（节点）、`gKPowEnXWzil.yaml`（组）、`rQPkKclEsQ5L.yaml`（规则）。【03】
- Roxy 解密点：`browser-cache\<dirId>\lumi.conf`（AES-256-GCM，key/iv 硬编码在 01 文档）→ 读 `windowName`/`fproxy`。【01】
- 系统代理：`HKCU\...\Internet Settings` + `InternetSetOption` 通知。【02/03】

### D. 付费/合规类（第二任务）
- 官方 API：只收支持地区的 Visa/MC/Amex；**预付卡不能买 API credits**；credits $5 起、1 年过期。
- 虚拟卡市场 2024–2026 大面积关停，剩余 U 卡直付成功率低（30–40%，社区数据）。
- **桌面端 + Codex 的首选实付路线：美区 Apple ID + App Store 礼品卡 + iOS 内购 Plus（≈¥140/月）**；注意 Apple ID 与 ChatGPT 账号一次性绑定。
- 合规事实：大陆/港澳不在支持地区；非支持地区访问可能导致账号停用。

## 总结（关键结论）

1. **技术可行性已验证**：美国静态 IP 通道（roxynet 复用，出口 `<美国静态IP>`）与 Clash 控制通道（命名管道 API）都在本机跑通了，程序A/B 的实现路径没有未解的技术风险，只剩工程落地。
2. **"全程"的关键**：系统代理 + TUN 双通道 + Clash 里按"进程 + 域名"把 OpenAI 流量钉死在美国静态 IP 上；另外要关掉 ChatGPT 的开机自启，防止"无代理裸启动"。
3. **两个程序的边界很清晰**：程序A = "按顺序把上面每件事检查/修复一遍，最后打开应用并验证"；程序B = "按'应用→Roxy→系统代理→Clash 内核→cmd 窗口'的顺序拆掉一切，最后验证网络回到直连"。
4. **风险都在可控范围**：最大的两个外部依赖是 Roxy 窗口和 Clash；设计里都有降级/提示路径。唯一无法脚本化的官方优雅退出（Roxy 托盘退出）已用"温和关闭+兜底强杀"缓解。
5. **第二任务（API 充值）的实话**：对个人用户，2026 年的现实路线是订阅（美区内购）而不是 API 充值；如必须 API，小额试水 + 可靠渠道 + 接受拒付风险。

- 实施中解决的关键问题（详见 01/03/06 文档）：
  1. 扩展文件写盘 ≠ 内核已加载 → 用 `GET /rules` 检查运行中的规则，缺了就重启 Clash；
  2. "全局模式 + 选中本项目组"会与 roxynet 的上游跳板形成**回环**，改用"专门放行 `ipinfo.io` 走 GPT-US 组"的规则路径做出口校验；
  3. Windows PowerShell 5.1 读取**无 BOM 的 UTF-8** 脚本会按 GBK 解码并可能解析失败 → 所有 `src\tools\*.ps1` 均以 UTF-8 **带 BOM** 保存（后续手动编辑这些文件时务必保留 BOM）；
  4. **`.cmd` 启动器必须纯 ASCII**：cmd.exe 按控制台代码页（简中=GBK）解析批处理，含中文的 .cmd 会解析错乱（实测把中文当命令执行）；中文输出交给 Node（`chcp 65001` 之后）；
  5. Roxy 的未文档化 CLI（`--roxy-action launch-browser`）在"主程序已在运行"时作为第二实例不可靠 → 优先按 `dirId` 识别已打开窗口；**窗口真的没开时用"带窗口参数的首次启动"实测可靠**；
  6. **roxynet 建链依赖"窗口打开那一刻的系统代理"**：顺序必须是"先 Clash/系统代理，再打开 Roxy 窗口"，否则静态通道一律 502；程序A 已按此排序并带自愈（重启 Roxy 重建链路）；
  7. **只杀 Clash 内核会被服务自动拉起**：真正关闭要 `Stop-Service clash_verge_service`；服务被停后由程序A 通过"助手计划任务"（`GPTProxy-StartClashService`，程序B 提权时创建）免 UAC 拉起；
  8. 所有外部命令都加了超时 + 10 分钟看门狗（首轮实测曾出现 PowerShell 子进程卡死导致流程停滞）；每次运行会写日志到 `state\logs\start-*.log` / `stop-*.log`。
